# Start here

Open this extracted folder in local Codex on your Mac. Read HANDOFF.md for the scope, constraints, observed tests, static findings, and milestones.

The evidence directory contains files statically extracted from Razer’s official installer. They are reference material, not a runnable app. Native libraries have not been fully decompiled. The Pro Type Ergo-specific Bluetooth protocol is still unknown.

MANIFEST.json records the evidence hashes. The full installer can be downloaded from the official URL in HANDOFF.md if more components are needed.

Suggested initial instruction: Read HANDOFF.md and inspect the included evidence. Continue the Bluetooth-first Synapse replacement project, beginning with device-specific input/protocol discovery. Preserve my MX Master 3 settings and do not modify system drivers as part of static analysis.
