# First public preview

Ergo Control is a lightweight, local macOS menu-bar app for the Razer Pro Type Ergo. It runs without Razer Synapse and stores settings on your Mac.

- Map M1–M5, AI, media buttons and both dials to shortcuts, text, macros and application actions.
- Create application profiles and command-dial modes, with on-screen mode, brightness and battery indicators.
- Control keyboard lighting, brightness, battery dimming and wireless sleep.
- Choose function-key actions, including Spotlight/Raycast and Apple dictation/Fluid Voice.
- Optionally connect Codex chat keys and keyboard status lighting for working, approval and completion.
- Launch at login, activate saved mappings automatically, and inspect local app logs.

This build includes the verified right-roller volume/mute and media-button input repair.

## Install

Download the universal DMG, open it, drag **Ergo Control** to **Applications**, eject the image, then open the Applications copy. Follow **Read me first.txt** and **Setup & diagnostics** for permissions and the optional full keyboard-control helper.

**Self-signed; not Apple-notarized.** macOS may require **Privacy & Security → Open Anyway** for the app and helper installer. Input Monitoring and Accessibility permissions are required for mappings; the separate helper also needs Input Monitoring. No Apple Developer membership is required to build from source.

Requires **macOS 14 or later**. The DMG includes Apple Silicon and Intel binaries; hardware testing so far is on Apple Silicon with a Pro Type Ergo over Bluetooth.

## Known limitations

- Mapping support is Bluetooth only. USB/receiver mapping and Intel hardware behavior are not validated.
- After a Bluetooth disconnect, mappings stop safely and the keyboard's original mode is restored once reconnected. Enable mappings manually to resume; automatic reconnection does not currently reactivate them.
- The small physical command-dial color indicator is unsupported during mappings. On-screen mode indicators are available.
- Focus-based media routing is experimental and off by default; normal media routing uses macOS.
- Custom status-wave timing depends on Bluetooth throughput. Battery-runtime improvements have not been measured; displayed charge is the keyboard's own estimate.
- If the release signer differs from an earlier local build, remove the old helper using the old app before installing the release helper. Keep the old app until migration is complete.

Profiles and settings are preserved across updates. This release contains no Razer software or private research captures. A SHA-256 checksum accompanies the DMG.
